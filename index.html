Web Design Project

Signal & Structure

A progressive practice site built to demonstrate core HTML skills through linking, media, structured content, semantic layout, and accessible forms.

Project Aim

To build a clear, accessible, and well-structured web project that applies the foundational ideas introduced across six practical labs while maintaining readable design, logical navigation, and meaningful content.

What The Project Covers

  • Lab 1 Page structure and essential HTML hierarchy
  • Lab 2 Linking, anchoring, and visual styling basics
  • Lab 3 Multimedia with captions and accessibility
  • Lab 4 Lists, tables, captions, and summaries
  • Lab 5 Semantic layout using meaningful HTML5 tags
  • Lab 6 Forms, labels, validation, and better input flow

Design Direction

The layout keeps the classroom-document feel from the provided screenshots: calm spacing, strong headings, restrained color, and a clean reading rhythm instead of a flashy template.

This keeps the presentation and the hosted site aligned with the original task instructions while still feeling polished and personal.

Prepared as a concise project showcase for presentation and GitHub Pages hosting.
