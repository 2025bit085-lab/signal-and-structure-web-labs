# Pearl Trails Uganda

This repository contains:

- a basic GitHub Pages site for a student web design project
- a three-slide PowerPoint presentation
- source files used to generate the presentation

## Project Idea

This project is a simple tourism website idea based on Uganda.
It follows a student format:

- background of the topic
- where the current system is lacking
- what the website is trying to improve

## Where The Current Situation Is Lacking

- Information about tourism services is often scattered in different places.
- Some visitors may fail to find trusted booking or travel details in one place.
- Smaller tourism services may not get enough visibility online.

## Proposed Direction

The website is meant to give users one simple place where they can:

- read about destinations
- learn about services
- make simple booking inquiries
- contact the team easily
